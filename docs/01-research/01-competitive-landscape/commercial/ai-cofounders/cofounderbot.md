# CoFounderBot

**URL:** https://cofounderbot.com  
**Category:** Autonomous multi-agent “AI team” that builds and runs products  
**Status:** Early access / free to start (one active project). No credit card.  
**Maturity:** Landing-page mature, company-outcome unproven (no public cohort metrics found).

## Stated product

Seven named agents coordinate around the clock:

| Agent     | Stated job                                           |
| --------- | ---------------------------------------------------- |
| Director  | Coordination, approvals, user communication          |
| Ideator   | Market research, brainstorming, competitive analysis |
| Architect | System design, tech decisions, task breakdown        |
| Coder     | Code, reviews, git                                   |
| Tester    | Tests, bugs, performance                             |
| Marketer  | Content, social, SEO, landing pages                  |
| Operator  | CI/CD, deploy, monitoring                            |

Plus listed specialties: data/analytics, customer success.

Workflow: describe a vision → agents research/plan/code/test → human approves deployments and high-risk actions.

Other claims: “AI Team Computer” (terminal, files, preview, agent dashboard); smart model routing; persistent memory; cron-style scheduled jobs; **bring your own OpenRouter key** (user pays inference; CoFounderBot orchestrates); row-level isolation.

## Strengths (if the product matches the page)

- Correct control split: **low-risk auto, high-risk human**.
- BYOK is honest about LLM cost.
- Covers the “build the product” hole that LivePlan leaves open.
- Scheduled jobs are the seed of an ops runtime.

## Weaknesses / risks

- **Customer discovery is a bullet under Ideation**, not a gated phase. This automates the developer trap.
- Marketing examples (crypto tracker, multiplayer game, POS, password manager) are a **demo zoo**, not a methodology.
- No India legal, no unit-economics engine, no evidence store.
- “Runs while you sleep” is a claim that, historically, autonomous coding agents still fail on long-horizon coherence (this is exactly why Anthropic published harness-design work).

## What to steal

- Named org chart of agents (founders understand “marketer” better than “worker_3”).
- Approval policies as data, not as a chat instruction.
- BYOK / usage meter so we do not hide token costs.
- Visual “team computer” for trust (watching agents work).

## What to avoid

- Shipping code before a Revenue Gate or interview gate.
- Promising unsupervised customer emails. That is how you burn the market and violate DPDP/spam rules.
