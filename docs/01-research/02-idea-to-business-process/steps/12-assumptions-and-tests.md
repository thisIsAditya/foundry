# Step 12 — Key assumptions and tests

**Phase:** 3  
**Sources:** Aulet 20–21; Lean Startup leaps of faith; LEANSpark 90-day / 2-week sprints.

## What this step is

List the **leaps of faith** still sitting under steps 01–11. Then design the cheapest test for the riskiest ones.

Typical leaps: they will switch from Tally workaround; economic buyer is the owner; churn < 5%; we can acquire via WhatsApp groups; CA will recommend us; we can deliver GST-correct invoices; API X will be allowed.

## How to do it

1. Extract assumptions from every `ASSUMPTION:` tag.
2. Rank by “if false, we are dead.”
3. For each top item: test type (interview, pretotype, concierge, LOI, supplier quote, legal memo, landing page), cost, time, pass/fail number **written in advance**.
4. Run tests in 1–2 week slices (Maurya).
5. Update the canvas states: guess → tested → validated/invalid.

## Evidence required

- A living `assumptions_and_risks.md` (Harness).
- Pre-registered pass/fail. No moving targets after seeing data.

## Agent

Assumptions / Experiment Designer Agent — plus Critic that rejects unfalsifiable tests (“we will see if people like it”).
