# Step 16 — Build the MVBP

**Phase:** 3  
**Sources:** Ries; Aulet 22–23; YC launch early; builder tools (Lovable, Bolt, Cursor) as workers, not strategy.

## What this step is

Make the scoped MVBP real enough to **deliver value and collect payment**.

Paths:

- **Concierge:** Google Sheet + WhatsApp + Razorpay link. Often correct in India.
- **No-code / AI builder:** one workflow.
- **Custom software:** only if the hypothesis _is_ the software (e.g. a Tally connector).

Quality bar: reliable for the beachhead, embarrassing for the vision. Instrument the metric from step 14. Put a payment or invoice path in the first release.

## What this step is not

Hiring a 6-person engineering team. Choosing Kubernetes. Building admin for 12 roles.

## Agent

Build Agent (optional worker) + Prompt Engineer — emit builder prompts; human ships. Coding agents (OpenHands, Cursor) are tools.

## Take-away

Working MVBP + `runbook.md` (how to operate the concierge if manual).
