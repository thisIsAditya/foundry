# Idea2MVP products (two different sites)

The name is used by at least two products. Do not conflate them.

## Idea2MVP.cloud — analysis + mentorship funnel

**URL:** https://idea2mvp.cloud  
**Operator:** Mykhailo Koblychenko (fractional CAIO; claims 10+ companies).  
**Price:** Free analysis.

Wizard: problem, solution, audience → AI scores **six dimensions** (market potential, competitors, SWOT, business model, risks, overall) → submit for human review → selected ideas get mentorship.

**What it is:** lead magnet for a human expert, not a platform.  
**Steal:** six-dimension scorecard as a critic output.  
**Avoid:** “the best ideas will be built for you” as our model unless we are an actual studio.

## I2MVP.dev — validate, deck, deploy

**URL:** https://idea2mvp.dev  
**Pitch:** “Ship validated ideas, not guesses.” Evidence-based validation, auto pitch deck + value proposition canvas, one-click MVP deploy and code export.

**Pricing (site):**

| Plan | Price | Notes |
|---|---|---|
| Free | $0 | 1 project, 1 validation run, md/PDF, MVP preview time-limited |
| Pro | $29/mo | Unlimited projects/runs, PPTX, full MVP, code export/deploy |

**What it is:** the compressed version of our whole vision (validate → artifact → build) at consumer SaaS prices.  
**Gap vs us:** “validation” that can run in one click is probably web research + LLM, not 15 interviews. One-click MVP is a prototype, not an MVBP (paying customers).

**Steal:** code export so the founder is not trapped.  
**Avoid:** one-click “validated” badge.
