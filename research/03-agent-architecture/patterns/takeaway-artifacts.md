# Pattern: take-away artifacts

The founder leaves with a **git repo or ZIP** they own:

- `pack.json` (source of truth)  
- Human markdown views (canvas, PRD, plan, India checklists)  
- `model` (spreadsheet/JSON)  
- HTML optional (Harness Mode 5)  

SaaS may host the live ops, but **export cannot be paywalled** for the strategy pack. That is how we beat LivePlan hostage fear.

Generate the 30-page plan and 10-slide deck **last**, from the pack, when the user has a bank or investor as the next action — FounderOS skill routing.
